The hosts around `mountDiffView` each need to know about the selection:

- Pull request page (`builtin_plugins/github/pull-page.js`): the selection is held per
  page and shared by its tabs; `comparison-prefetch.js` (prefetch, keep, warmer) keys
  include the types so a kept answer is never the wrong set; the page-top Diff summary
  (`mountDiffSummary`) stays the whole change set.
- Commit page (`git-panel.js` comparison reuse, `summaryHost`): same rules;
  `git.commit-comparison-reuse` session extended.
- Jumps to a file the filter hides (Diff summary rows, `scrollToFile`, `lookupFile`,
  links into a file): say it is hidden by the File type filter and offer to show it
  (clears the filter, then jumps) rather than failing silently.
- Extend the existing DOM sessions (`github-pull-prefetch-session.js`,
  `diff-file-jump-session.js`, `git-commit-history-session.js`) and their goldens.
