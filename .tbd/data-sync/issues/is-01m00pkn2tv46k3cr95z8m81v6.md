Tighten the vertical spacing between disclosure heading text and the divider line through the shared section-heading design system.

Required behavior:
- Introduce or extend a named design token for the text-to-divider inset used by section headers with a bottom rule; do not leave the overview value as an isolated padding literal.
- Reduce the current overview heading bottom padding so the divider sits slightly closer to the title and trailing chevron.
- Apply the same token to File Totals, File Types, README, and future overview section headers that use this divider treatment.
- Keep typography, chevron size and placement, divider color and thickness, content width, and the spacing below the divider unchanged unless visual verification shows a direct conflict.
- Do not force a divider onto disclosure contexts such as Markdown metadata that intentionally omit one; this is consistency for divider-bearing section headers, not every details element.
- Preserve the same rhythm at every responsive width and under reduced motion.
- Add a CSS contract test for shared token ownership and visually verify representative wide, medium, and narrow overview layouts.
