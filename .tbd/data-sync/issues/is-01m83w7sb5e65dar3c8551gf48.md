The Docs tab on the pull request page (mb-u173, PR #751) fetches its narrowed comparison (group=type:docs) when the tab opens, instead of joining comparison-prefetch.js as the Changes tab does. The prefetch's signature is pinned by tests/test_diff_browser_js.py (prefetch: (comparison, signal) =>), so the narrowed request needs its own prefetch key or a narrowing argument there. Done when a page that prefetches Changes also has Docs ready, measured in a real browser on a pull request with many files, and the pull page session pins the request.
