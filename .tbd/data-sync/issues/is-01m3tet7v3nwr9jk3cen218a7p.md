Part of the test-suite review epic. AGENTS.md ("Changing This Guidance") says to prefer a check to a sentence, so this bead proposes checks, and one short rule only where a check cannot reach.

## Recurring causes found by the survey of 2026-09-30

1. A string assertion per fix. Feature commits 7e2296f3 and 26c9eb00 have new `assert "<code>" in app_js` lines as their only test evidence; 311e8398, ce2bf349 and 3488943f are test-only commits that re-pin strings after a refactor. By reading, about 280 of 509 tests in 36 files assert source shape rather than behavior.
2. A new wrapper file per DOM script. 53 `tests/test_*_js.py` files, 32 of them a copied template, each with its own silent Node skip (176 skip sites).
3. A Python test beside every golden block. 46 CLI tests duplicate a tryscript block; nine cache route tests restate `cli-api-cache.tryscript.md`; nine pull-request tests restate the pull goldens; about 20 wrapper tests restate a `cli-ui-*` golden.
4. A private helper per test file. 15 `_git` definitions, 53 fake request classes, 45 DOM stub classes, 49 imports from other test modules.
5. A local fix for a global leak. The 2026-09-24 session-generation failure was fixed with one reset in one test (commit 2a2ec603) rather than in `tests/conftest.py`.
6. Goldens that grow without a bound: one file of 2,434 lines, a 152-line block pinned twice in one file, one record printed about 18 times.

## Proposed checks (in `make lint-check`, each with a negative probe)

1. Source-shape ratchet. Count Python test assertions that test a string against text read from `src/metabrowser/static` or `src/metabrowser/builtin_plugins`. Record the count per file in a committed allowlist; fail when a file's count rises or a new file appears. Files move out of the list, never in. This follows `ci-and-gates-rules`: "Ratchet toward strict; never loosen the default."
2. DOM script registration. Every `tests/dom/*-behavior.js` and `*-session.js` is run by the shared runner's manifest or by a golden; fail on an orphan. (Lands with the Node runner bead.)
3. Golden size threshold, and every recorded fixture named in `make golden-update`. (Lands with the golden machinery bead.)
4. No imports from `tests.test_*` modules.
5. No bare `pytest.skip("node not available")`: use the shared requirement helper. (Lands with the tiers bead.)

## Proposed rule (one paragraph in `docs/e2e-testing.md`, under "Adding Coverage")

For a change to browser JavaScript, extend or add a browserless session; do not add an assertion on source text unless the property is paint or platform behavior with a named exemption. For a change to CLI or route output, extend a golden; add a Python test beside it only for an invariant the transcript cannot show, and say which. The reason: a text assertion fails on a refactor that keeps the behavior and passes on a behavior change that keeps the text. Delete this rule if check 1 reaches zero and stays there.

## Acceptance

- Each check fails on its probe and passes on the tree.
- The allowlist for check 1 is generated by the check itself, not typed by hand.
- The rule states its reason and its removal condition, as AGENTS.md requires.
- `make verify` is green.

## Must NOT be done

- Do not write counts into prose in `AGENTS.md` or `docs/development.md`; the check reports them.
- Do not ban source-text tests outright: the paint-exempt contracts (`tests/test_preview_frame_contract.py`, the CSS geometry tests named by the parity table) are honest and stay.

No release label: guidance and ratchets do not gate the landing. Checks 2, 3 and 5 are built in their area beads; this bead owns checks 1 and 4 and the rule.
