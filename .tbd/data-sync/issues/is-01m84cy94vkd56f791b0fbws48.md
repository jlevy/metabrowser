User decision 2026-11-23 (morning question from mb-u173): the pull request page's Docs tab is hidden when the pull request changes no documents, instead of always showing with an empty state. Membership stays route-owned: the page reads the comparison's File type counts (view=types, the type:docs group) and shows Docs only when that count is above zero. A direct /pull/<n>/docs address keeps its empty state. Done when the tab bar, the D key and the session and golden pin both cases.

## Notes

PR https://github.com/jlevy/metabrowser/pull/753. Verified in a real browser on a live repository: a PR with 7 changed files and no documents hides Docs and D does nothing; /pull/<n>/docs still opens with its empty state; a PR that changes documents keeps Docs.
