Residual of PR #383 B3 (review https://github.com/jlevy/metabrowser/pull/383#pullrequestreview-5882937219). 2f5970d2 made the eager queue in static/plugin-sdk.js a Set that a queued detach() and view composition's pre-load net delete from (0 eager bytes). An attachment whose AbortSignal aborts before static/plugin-shortcuts.js loads still stays queued, element and all, until the facade drains it (the facade then binds nothing). Ready fix in queueShortcut after _shortcutQueue.add(queued): options?.signal?.addEventListener?.("abort", () => _shortcutQueue.delete(queued)); with a plugin-shortcuts session case (attach with a signal, abort, the queue size stays). Cost measured by gzip as check_startup_scripts does: +24 bytes to plugin-sdk.js (17,314 -> 17,338). With B1's +32 bytes in app.js the folder shell is 179,693 of 179,711 (18 under), so this would be 6 over. Waits on the startup-budget re-derivation running in another session; do not change the budget number or trim docs to fit.
