Phase 4, macOS app (plan: The macOS App), split from mb-mtpe. The repository bar for an undecided clone or a new provider: Trust (grants confined where a backend exists, by running metab ROOT --plugins-trust --expect SHA256 with the hash it displayed), Review (the full consent and the choice of full), and Not Now (for the window, not recorded). A missing environment is reported with what the repository documents and never set up. Each command and key the bar reads is declared in apps/macos/metab-contract.toml with its golden block and a changelog fragment, the metab release is a minor, and MetabRequirement.minimumRelease is raised; there is no path for an older metab. A live test stops a folder and checks that no worker remains. README and arch-macos-app.md sections.
