Present at the base and kept by PR #449, whose scope is byte-identical answers: GitDiffSource._rev_parse catches every GitError, GitTimeoutError included, and raises DiffSourceError('unknown revision ...'), which the comparison route answers as a 404 naming the revision, where a slow repository is not an unknown revision. Noted in review A of #449 (A4, https://github.com/jlevy/metabrowser/pull/449#pullrequestreview-5913959566). Fixing it changes a refusal's status and message on both the batched and one-at-a-time paths (src/metabrowser/diff/adapters/git.py _rev_parse and _rev_parse_together), so it needs its own change with the route's golden.
