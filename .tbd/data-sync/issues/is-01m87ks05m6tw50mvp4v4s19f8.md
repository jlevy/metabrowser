A page-1 preview image keyed by a hash of the PDF's bytes (a pin's blob ID; a folder's hash memoized by mtime fingerprint), renderer version and size, in a previews area of the cache root, written atomically, LRU-bounded by a measured size. Rendered by pypdfium2 in a bounded subprocess, declared by the pdf plugin as plugin-only (mb-vdh3). Server-side parsing of untrusted PDFs is justified against the threat model (mb-31vb). The card shows in diffs, Markdown embeds and folder overviews, lazily; on the file page it stands in while the viewer starts. Click opens in the default app, or downloads where there is none or the host cannot open files; Download always. A golden pins render, reuse, new key on change, and the image-less card on failure.
