Acceptance criteria promise a /blob/<ref>/<path> URL opens that file at <ref>, but the URL grammar has only /view/<path> (served tree, no revision) and /commit/<rev>[/<inner>] (a change set, not file content). docs/architecture.md explains deliberately why revisions are not addressable inside /view/. Works when <ref> resolves to the pinned active_revision, which is the common case; fails for any other branch, tag, or SHA. Line anchors are a second unscoped surface.
