From the senior review of #666 (A4). A kept pull manifest (repos/<key>/github-pull-manifests/pull-<n>.json) holds the store's absolute repository.git path in its 8-element identity (builtin_plugins/github/pull_manifest.py _identity, key[0] from diff/sidekick.py comparison_cache_key), and its store token (http_caching.store_tag) hashes the path too, so every manifest is a miss after the f03 move and after a user moves the cache directory. Safe (a miss, never a wrong answer) but each pull request's file list is recomputed once (about 77 ms) and the old manifests stay until that pull request is read again; the bank is never pruned. Make identity and the epoch slot independent of the path (a persisted-format change: bump schema_version, and decide what the store token keeps), then the f03 move and a cache move keep the bank. Not done in #666 because it changes the manifest record and the HTTP store token.
