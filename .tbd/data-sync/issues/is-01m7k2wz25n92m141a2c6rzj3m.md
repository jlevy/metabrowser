Phase 1 of the publishing plan. Add apps/macos/scripts/check-release.sh and make macos-check-release TAG=macos-vX.Y.Z for a draft or published release: download the image and checksum with gh into a scratch folder; check shasum -a 256 -c, the GitHub asset digest, gh attestation verify when an attestation exists, and gh release verify-asset once published with immutable releases; apply a quarantine attribute if the download has none, labelled a simulation; run check-dmg.sh with NOTARIZE=1. With LAUNCH=1, copy the app out of the image into a scratch Downloads folder still quarantined, open it, wait for the person to answer Gatekeeper, check the process runs from an AppTranslocation path and shows the launch notice, relaunch and record whether it is still translocated, then move it and check a launch from the new place. It runs the unmodified release bundle, so it refuses while a release copy is running and backs up and restores that identity's defaults and the shared session.json. Done when it passes on the first draft release and again once published, and the launch part has been run by the owner.
