Phase 1 of the publishing plan; the interactive launch is mb-u36j (PR #485 A20). Add apps/macos/scripts/check-release.sh and make macos-check-release TAG=macos-vX.Y.Z BUILT=local|ci for a draft or published release: download the assets with gh release download into a scratch folder; check shasum -a 256 -c and the GitHub asset digest; with BUILT=ci, require the build provenance attestation, verified with gh attestation verify FILE --repo jlevy/metabrowser --signer-workflow jlevy/metabrowser/.github/workflows/macos-release.yml --source-ref refs/tags/macos-vX.Y.Z (PR #485 A3, B4); once published, gh release verify-asset for the immutable release, and that the release is not Latest (gh api repos/jlevy/metabrowser/releases/latest names another tag; PR #485 B6); print which provenance was verified. The build kind is an input, not inferred, so a CI build that lost its attestation cannot pass as local. Apply a quarantine attribute if the download has none through URLResourceKey.quarantinePropertiesKey with a small Swift helper, labelled a simulation (PR #485 A14); run check-dmg.sh with NOTARIZE=1. Asset names come from the one function in common.sh (PR #485 A6). Done when it passes with BUILT=local on the first draft release and again once published, with BUILT=ci on the first CI draft, and scripts/test-scripts.sh shows a missing attestation failing BUILT=ci.
