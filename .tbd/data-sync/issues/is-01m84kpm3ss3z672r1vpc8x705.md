Found by #740 review C (C1), https://github.com/jlevy/metabrowser/pull/740#pullrequestreview-6024990424. unfetched_origin_address (src/metabrowser/cache/lender.py) cuts the address at the first ? or # before redact_userinfo runs, so http://user:pa?ss@host.example/octo/demo.git is shown as http://user:pa, in origin.address of /api/source/refs, the chooser, and --api output. Fix: redact first, with the userinfo running to the last @ before the first / (which also covers http://a@b@host/x.git), then cut; add the reviewer's rows and http://a@b@host/x.git to test_an_origin_reached_another_way_is_one_metabrowser_cannot_fetch.
