The Files panel already swaps its data source — filesPanelUsesRecentSource() renders /api/recent through the same tree renderer. A comparison is a third source, scoped like a filter down to changed files, decorated with the full indicator set from the File Diff Format. Selection routes through the same navigateToPath path everything else uses. No new tree machinery.
