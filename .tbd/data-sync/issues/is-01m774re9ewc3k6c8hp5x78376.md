Native shell half of the research's item 2, a stable origin per root (H87's relaunch reading). apps/macos is on main (#341) and already serves on one host spelling, 127.0.0.1 (apps/macos/Sources/ShellCore/Supervision/ServerLaunch.swift), with the persistent default WKWebsiteDataStore (apps/macos/Sources/ShellCore/Web/WebConfiguration.swift). What remains is the port: CLIServeLaunch takes the first free port walking up from 8411, so a root can come back on another port, and WebKit keys its disk cache by host and port (the research: 17 requests on the same port, 103 on another). Once mb-qzny's host mode lands, launch each root on its sticky port and measure relaunch requests with the WKWebView probe.
