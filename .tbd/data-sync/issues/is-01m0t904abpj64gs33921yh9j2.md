The provider CatalogQuery runs in a worker, but InventoryCoordinator.read currently iterates every CatalogProjection record under the coordinator's async lock to snapshot overlay decorations, even though catalog projections return no decorated entries. _read_catalog then iterates every record again on the request event loop to build path/extension tuples before off-loop JSON encoding. Remove the unused catalog overlay traversal and move all bulk catalog response materialization into a worker while preserving pinned-page coherence, ETag identity, cache behavior, and the minimal wire shape. Add structural and heartbeat-style regression coverage.

## Notes

Coordinator catalog decoration joins are now opt-in; active_tracker opts in and bulk Quick File delivery does not. Catalog pages remain immutable tuples through the request path and are flattened into wire dictionaries only inside asyncio.to_thread(_encode_catalog). Focused coordinator, activity, catalog, and structural tests pass.
