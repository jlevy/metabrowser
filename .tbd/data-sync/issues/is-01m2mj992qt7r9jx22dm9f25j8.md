The generic browser evidence harness checks valid or invalid verdicts and the result envelope but does not prove that a successful parser returns the complete input record unchanged or avoids mutating its input. A parser that accepts a valid case and returns an empty object can pass. Define v1 parsers as validation-only, compare the success value with the pre-parse record using deep strict equality, verify the input remains unchanged, and add synthetic record-loss and mutation regressions.
