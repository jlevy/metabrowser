Offer View file and View at base for PR diffs in both local checkout and managed modes. Use the comparison already on screen, its resolved merge base and head, and its old/new exact file path. Render Markdown and Source through a revision-scoped route. Keep relative assets in that snapshot and remote content inert even on a trusted folder server. Preserve the live checkout and served pin, retain Back context, and cover rename/add/delete, dirty worktrees, stale results, concurrent reads and warm offline reopen.

## Notes

Reviewed revision-link design in PR #346 at 63d5d7fab9fd1dadb2c1481c7ad24d4ded37ea0a (https://github.com/jlevy/metabrowser/pull/346) requires bounded durable admission, exact merge base and head paths, explicit untrusted scope on every secondary read, and expiry/restart coverage. Works on both checkout and managed PRs without switching the server pin.

Implemented immutable View file and View at base links for managed and checkout modes. The built-in browser opened the head document from a managed cache and the exact merge-base document from a checkout. A fresh checkout server reopened the retained URL with gh disabled. Tests cover missing comparison, type-aware raster and binary rendering, bounded source offsets, and refused unissued pairs.
