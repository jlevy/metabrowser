- A repository’s first visit fills its pull-request catalog as fast as GitHub answers,
  one GraphQL call for each 100 pull requests, so Quick Search across every state and
  the ref chooser’s pull requests by branch are complete as soon as those calls are
  read. The descriptions of rows not on screen, one call for each 8, take what the
  background prefetch leaves of its share while it has nothing to read, so a repository
  of 800 pull requests has most of them within minutes and the rest within about an
  hour; the rows on screen are described at once, as before.
