- **A stack’s page is spaced as a pull request’s page is.** Guided Review on a stack’s
  page keeps to the reading column, as on a pull request’s page, where it had run across
  the whole pane; Docs and Changes still use the full pane.
  The members’ card is a page card whose rows start at the same inset as every other
  card’s content, so a member’s icon lines up with Guided Review below it.
  Docs or Changes that could not load say so in an error notice with Retry, as on a pull
  request’s page
  ([The Stack Page’s Spacing](docs/design-system.md#the-stack-pages-spacing)).
