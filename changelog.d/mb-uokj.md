- **A branch or tag chip is one size everywhere.** A chip’s name was a little larger on
  a commit’s page and in a pull request’s header than in the navigation’s Commits list,
  in a box of the same height, so it sat low in the box there.
  A chip now has the navigation’s size in every place it is drawn, with its name
  centered the same way ([Branch Chips](docs/design-system.md#branch-chips)).
