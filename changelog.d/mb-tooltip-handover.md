- Moving the pointer straight from one link onto the next no longer leaves the first
  link’s card up beside the second for as long as the pointer rests there.
  The second link’s card now comes up at its own place.
  The same goes for any element with a short tooltip, such as moving from one onto a
  word inside the next one.

- A link card whose title the page reads in time now comes up on the tooltip’s own delay
  with the title in it.
  It used to start the delay over, so a title read quickly delayed the card by more than
  half a second ([A Tooltip Holds Still](docs/design-system.md#a-tooltip-holds-still)).
