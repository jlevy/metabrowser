- **Docs keeps a followed head’s line and your choice through a reload, as Changes
  does.** Docs follows new pushes with the same line over the new diff, but a reload,
  which a push makes on a repository URL, dropped that line there, and the next push
  replaced an earlier diff you had gone back to with the newer one.
  Both now outlast the reload, with **Show the newer changes** offered.
  See [Staying Current](docs/reviewing-pull-requests.md#staying-current).
