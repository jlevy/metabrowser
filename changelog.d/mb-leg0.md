- A diff’s file bar puts Copy path right after the file’s name and change counts, shown
  while the pointer is on the bar or the keyboard’s focus is in it, and puts a file’s
  **Rendered** | **Source** chooser at the bar’s end, before View file or View on
  branch. A long path is cut short with Copy path still beside it, and a bar too narrow
  for both groups gives the name its own line.
  See [Diff File Bar](docs/design-system.md#diff-file-bar).
