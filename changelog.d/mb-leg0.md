- A diff’s file bar reads in one order: the file’s name, then Copy path, shown while the
  pointer is on the bar or the keyboard’s focus is in it, then the change counts and any
  note, then **View file** or **View on branch**, and last a file’s **Rendered** |
  **Source** chooser, alone at the bar’s end.
  A long path is cut short with Copy path and the counts still beside it.
  A bar too narrow for its parts moves View file, and then the chooser, to the next line
  rather than cutting a control off, and a bar with the chooser does so before it cuts
  the name at all. See [Diff File Bar](docs/design-system.md#diff-file-bar).
