- The view header’s GitHub toggle now sits in the header’s upper right corner, level
  with the line above the title, at a fixed inset from the header’s top and right edges,
  so a title lower on the page no longer moves it.
  It is drawn as the app’s other toggles are: the Metabrowser mark, the view the page is
  in, in the accent color on the selected fill instead of gray, and the GitHub mark
  muted until the pointer is on it.
  It keeps both marks at every width.
  A pull request’s page has the same toggle in the same place, its GitHub mark a link to
  the pull request on github.com.
  See [View Headers](docs/design-system.md#view-headers).
