- A pull request’s **Docs** tab no longer offers the **Split** | **Unified** layout
  choice or its `L` key, which a rendered document has no use for: a document’s text
  diff there is always Unified.
  **Changes** keeps the choice
  ([Reviewing Pull Requests](docs/reviewing-pull-requests.md)).

- A diff file bar’s **View on branch**, on a pull request’s Docs and Changes, and its
  **View file**, on a commit’s page, now follow the file’s name and line counts, which
  leaves a file’s **Rendered** | **Source** chooser alone at the bar’s far end
  ([Diff File Bar](docs/design-system.md#diff-file-bar)).
