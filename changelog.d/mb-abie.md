- **The macOS app’s buttons say what they do.** In Settings > Runtime, Find Again is now
  Refresh and Reveal Logs is now Reveal Logs Folder, which is the Help menu’s name for
  it. In Settings > Check Setup, Check Again is now Refresh.
  When a folder’s server fails, the window offers Reveal Server Log, the File menu’s
  name for it, in place of Reveal Logs ([Settings](docs/macos-app.md#settings)).
