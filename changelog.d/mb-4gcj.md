- **A stack’s Whole stack row comes first in the Pulls tab, as in the stack menu.** Each
  open stack lists its Whole stack row directly under the stack’s row, above its pull
  requests, so `J` or Right from the stack’s row reaches it first and opens the stack’s
  page; Left from it goes back to the stack’s row.
  A key that moves on to a pull request takes the current-row mark from it at once
  ([Stack Groups in the Pulls Tab](docs/design-system.md#stack-groups-in-the-pulls-tab)).
