- **The macOS app’s Settings has tabs.** General holds how folders open and whether the
  last session reopens; Runtime holds the selected `metab`, Refresh, Choose metab…, and
  the places discovery looked; Plugins lists the runtime’s plugins; and Check Setup
  shows the setup report.
  Help > Check Setup… opens Settings at Check Setup, which runs the report each time it
  comes on screen, in place of a window of its own
  ([Settings](docs/macos-app.md#settings)).
