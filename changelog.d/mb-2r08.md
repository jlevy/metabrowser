- Rendered Markdown in a pull request’s Changes and Docs reads in the serif reading font
  again when Metabrowser runs with an editable or development KPress.
  Such a KPress’s version has a local segment, as in `0.3.10.dev10+5c60a81`, and the
  diff left out every KPress stylesheet whose address held its `+`, so a document read
  in sans until another part of the page loaded KPress’s styles.
  The diff now keeps any same-origin KPress stylesheet, whatever its version, and warns
  in the browser console when it leaves one out or one does not load
  ([Serif Is for Documents](docs/design-system.md#serif-is-for-documents)).
