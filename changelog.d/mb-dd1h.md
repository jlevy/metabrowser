- A guide’s row for another pull request reads as a stack’s member does wherever it
  appears: its title, its place in a stack, its number, and its author, such as “Fix the
  reader 1/3 · #455 · jlevy”.
  The place is bare in the guide’s own stack and names any other stack, “⧉300 2/2”, and
  its tooltip and its name for a screen reader say the stack in words; a pull request in
  no stack has no place ([Stacks](docs/design-system.md#stacks)).

- A guide’s row for a commit the checkout you are browsing lacks says so after its
  subject, so when it was committed still ends the row
  ([Ages End the Row](docs/design-system.md#ages-end-the-row)).
