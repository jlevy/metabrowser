- **A rendered document in Changes and Docs opens a GitHub link to the branch in
  place.** In a pull request’s Changes or Docs, a link in a Markdown file to a file or
  folder on the branch or commit being browsed, such as
  `github.com/<owner>/<repo>/blob/<branch>/docs/setup.md`, opens it here while the page
  shows the pull request’s head, as it does when you open the Markdown file itself.
  Away from the head, beside a checkout, or once another tab serves something else, it
  stays the GitHub link the document wrote, so a link never opens another commit’s files
  ([Links in a Pull Request’s Text](docs/reviewing-pull-requests.md#links-in-a-pull-requests-text)).
