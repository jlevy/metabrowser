- A pull request’s page has a **Docs** tab (`D`), between Conversation and Changes, that
  shows only the documents the pull request changes, each rendered with its changes
  marked and nothing folded, so its docs can be read on their own
  ([Reviewing Pull Requests](docs/reviewing-pull-requests.md)).
  `/api/plugin/diff/comparison` and the pull request comparison take `group=type:<id>`
  to keep one File type group’s changed files.
