- **App contract:** The View on GitHub button’s links carry the macOS app’s marker,
  which names no site: `data-web-view="open"` and `data-web-view="external"`, in place
  of `data-view-on-github="open"` and `="external"`; the button’s root keeps
  `data-view-on-github`. A page or plugin can mark any link `data-web-view="open"`, and
  the app shows a plain click on it in its web pane when the page is on a site the app
  knows, GitHub so far.
  See [View on GitHub](docs/design-system.md#view-on-github).

- In the macOS app, every site its web pane shows, such as github.com in View on
  GitHub’s popover, shares one store, as a browser profile does, and Metabrowser > Clear
  Website Data… clears one site or all of them.
