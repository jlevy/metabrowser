- **A rendered Markdown diff draws each run of changes as one band.** Consecutive added
  blocks, in a pull request’s Changes and Docs, a stack’s page, and a guided review,
  read as one unbroken green band, and consecutive removed blocks as one red band, with
  no white gap between two blocks; in Current, the new wording of a run of edits is one
  band too. Every block sits exactly where it sits without the band
  ([Rendered Diff Spacing](docs/design-system.md#rendered-diff-spacing)).
