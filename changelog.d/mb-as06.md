- On a pull request’s page, each pull request in the stack button’s menu is now one
  line: its state icon, its place in the stack in bold, such as “14/15”, and its title,
  cut short at the line’s end with the whole title in its tooltip.
  The menu no longer checks the current pull request or shows its number, which a screen
  reader still says; the current one keeps its highlight
  ([Stacks](docs/design-system.md#stacks)).
