- **The macOS app’s setup report is plain text that copies in part.** Check Setup drew
  each check’s details in a grid, where a value that wrapped ran over the next check.
  It shows the report as one block of monospaced text now, each check as
  `metab --doctor` prints one, which wraps under its own indent and scrolls; any part of
  it can be selected and copied, a selection stays on its text when Refresh runs the
  report again, and Copy Report still copies all of it
  ([Checking the Setup](docs/macos-app.md#checking-the-setup)).
