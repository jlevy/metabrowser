- **PDFs show inline on every source.** A PDF in a pinned revision, a GitHub repository
  or pull request, or a folder served `--untrusted` now opens in the browser’s own
  viewer on its file page, as a trusted folder’s does, instead of a note.
  The untrusted page admits a frame and an object from `/raw` alone, whose every answer
  keeps its sandbox; nothing else in the page can be framed or embedded
  ([the threat model](docs/project/architecture/arch-threat-model.md)).

- **App contract:** the golden line that pins `/raw`’s media type for the app now reads
  `viewer` where it read `note`, since a pinned revision’s PDF draws the browser’s
  viewer on its file page.
  What the app reads, `/raw`’s `Content-Type`, is unchanged, so the app and its
  `MetabRequirement.minimumRelease` are unchanged.
